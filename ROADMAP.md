# Roadmap

## Concluído

- Scrapers para plataformas freelance configuradas.
- Matching local por perfil profissional.
- Base de conhecimento em YAML.
- Proposal Intelligence determinística.
- Commercial Strategy determinística.
- Pricing Engine com horas, preço, faixa, confiança e premissas.
- Proposal Generator 2.0 com estrutura comercial.
- PDF Generator 2.0 com layout compacto e fallback legado.
- Dashboard Flask com listagem, detalhe, cópia de propostas, PDF e status.
- Testes automatizados para motores, PDF e dashboard.

## Em desenvolvimento

- Calibração contínua dos seletores dos scrapers conforme mudanças nas plataformas.
- Ajuste incremental da base `knowledge/` com novos cases, serviços e experiências.
- Revisão visual dos screenshots oficiais do repositório.

## Ideias futuras

- Exportar relatórios de oportunidades e conversão.
- Melhorar filtros do dashboard sem alterar o schema atual.
- Adicionar autenticação local ao dashboard, se o projeto for exposto em rede.
- Registrar histórico de versões de proposta.
- Adicionar testes end-to-end com navegador para o dashboard.
- Criar empacotamento Docker opcional.
