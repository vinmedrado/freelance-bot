# Base de Conhecimento Profissional — Vinicius Medrado

Esta pasta organiza o contexto profissional usado pelo matcher, gerador de propostas,
precificação e PDF comercial do freelance bot.

## Arquivos

- `identity.yaml`: identidade e posicionamento profissional
- `experience.yaml`: experiências e resultados comprovados
- `services.yaml`: serviços oferecidos
- `specialties.yaml`: áreas de especialização e gatilhos de matching
- `technologies.yaml`: tecnologias por categoria
- `portfolio.yaml`: projetos autorais e links
- `writing_style.yaml`: regras de escrita das propostas
- `proposals.yaml`: estrutura e lógica de geração
- `negotiation.yaml`: regras de negociação e escopo
- `pricing.yaml`: faixas e critérios de preço
- `project_matching.yaml`: regras para escolher experiências e cases relevantes

## Uso recomendado

O gerador deve carregar apenas os blocos relevantes para cada vaga ou projeto.
Não é recomendado enviar todos os arquivos integralmente para a IA em toda execução.

Fluxo sugerido:

1. Classificar o projeto
2. Identificar serviços e tecnologias relevantes
3. Selecionar experiências e cases relacionados
4. Calcular preço e prazo
5. Gerar proposta
6. Gerar PDF
