# Typography

## Fonte principal

Use `Inter` quando disponível.

Fallback:

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

## Hierarquia

| Elemento | Peso | Observação |
| --- | --- | --- |
| Produto | 750-800 | Forte, com letter spacing levemente negativo. |
| Títulos | 650-750 | Claros e compactos. |
| Corpo | 450-520 | Legível, sem excesso de formalidade. |
| Badges | 600-650 | Pequenos, técnicos e objetivos. |
