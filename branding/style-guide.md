# Style Guide

## Direção visual

FreelanceBot AI deve parecer uma ferramenta SaaS técnica para análise comercial, automação e geração de propostas.

Referências visuais:

- Stripe: clareza e acabamento.
- Vercel: minimalismo e contraste.
- Linear: interface sóbria e densa.
- GitHub: objetividade para desenvolvedores.
- Raycast: precisão visual e sensação de produto.

## Logo

- Usar `branding/logo.svg` em áreas horizontais.
- Usar `branding/icon.svg` em favicon, avatar ou espaços quadrados.
- Não distorcer proporção.
- Não aplicar sombras fortes.

## Ícones

- Preferir linhas simples e formas geométricas.
- Ícones devem comunicar ação ou estado.
- Evitar cliparts, mascotes ou ilustrações infantis.

## Espaçamento

- Usar múltiplos de 8px.
- Em banners, manter respiro amplo entre logo, título e chips.
- Em cards, preferir densidade moderada: informação suficiente sem parecer pesado.

## Cores

- Base escura: `#07111F`.
- Superfície: `#0B1728`.
- Destaque: `#D9A441`.
- Texto principal: `#FFFFFF`.
- Texto secundário: `#C8D3E2`.

## Tipografia

- Usar Inter ou fallback system-ui.
- Títulos com peso forte.
- Texto secundário com cor reduzida, não com tamanho excessivamente pequeno.

## Uso em GitHub

- README deve começar com o banner.
- Badges devem ficar logo abaixo do banner.
- Screenshots reais devem substituir os placeholders em `docs/images/` quando disponíveis.
