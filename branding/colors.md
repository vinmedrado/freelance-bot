# Colors

Paleta visual do FreelanceBot AI.

| Token | Hex | Uso |
| --- | --- | --- |
| `navy-950` | `#07111F` | Fundo principal, áreas hero, ícone. |
| `navy-900` | `#0B1728` | Superfícies elevadas. |
| `navy-800` | `#0F2340` | Cards, pills, container da marca. |
| `blue-600` | `#21466F` | Linhas, bordas e detalhes técnicos. |
| `gold-500` | `#D9A441` | Destaques discretos, IA, chamadas principais. |
| `white` | `#FFFFFF` | Documento/proposta, texto de alto contraste. |
| `slate-200` | `#C8D3E2` | Texto secundário em fundos escuros. |
| `slate-400` | `#8EA2BE` | Texto auxiliar, legendas e metadados. |

## Direção

- Usar azul escuro como base.
- Usar dourado apenas como sinal de inteligência, automação ou destaque comercial.
- Evitar gradientes agressivos.
- Manter contraste alto para leitura no GitHub.
